# 🚀 TaskFlow - Todo List

A modern, clean, and fully animated **Todo List** web application built using HTML5 and CSS3. Features a fixed vibrant navigation bar, custom checkmark animations, smooth line-through effects, and a stylish red theme.

---

## ✨ Features

* **Vibrant Fixed Navigation:** Colorful gradient header fixed to the top with interactive navigation links.
* **Animated Elements:** Smooth page entrance animations, staggered task list loading, and interactive hover states.
* **Custom Checkboxes:** Beautiful animated checkboxes featuring scale bounces and checkmark transitions.
* **Strikethrough Effect:** Automatically animates a smooth line across completed tasks with muted text styling.
* **Responsive Layout:** Designed cleanly for both desktop and mobile screens.

---

## 🛠️ Built With

* **HTML5**
* **CSS3** (Custom Properties, Flexbox, Keyframe Animations)
